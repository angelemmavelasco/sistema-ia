# Sistema de IA 
Proyecto de practica para la materia Arquitectura 
de Sistemas de Inteligencia Artificial.

Este sistema de IA sirve como asistente para responder preguntas de
dominio sensible. A traves de un LLM y RAG, se consigue una respuesta eficiente.

## Objetivo
Minimizar el tiempo de espera y busqueda, ademas de capacitaciones en un ambito en concreto.

 
## Componentes 
- Modelo 
- Inferencia 
- Configuracion 
- Documentacion

## Componentes principales y flujo
- Authentication.
- Authorization.
- RAG.
- PII Detection.
- Input Guardrails.
- Output Guardrails.
- Structured Outputs.
- Risk Classification.
- Human-in-the-Loop.
- Audit Logs.
- Observability.
- Evaluation.

## Tecnologias
- Python
- Golang
- Postgres / SQLite3 (dev)
- Docker
- Llama Guard
- DeepEval
